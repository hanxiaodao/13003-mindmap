# 蒸馏方法论：从真题反推考点

本文档是内容生产阶段的完整方法论。核心立场一句话：

> **从历年真题反推这门课真正如何考试，再从教材中补齐这些考点所需要的知识。**

不是"先总结教材，再找真题"，而是"先研究真题，再研究教材"。

优先级链条（冲突时上层胜出）：

```text
考试事实 > 考试规律 > 课程知识 > 教材补充 > 一般性背景知识
```

---

## 1. 三种素材的职责

| 素材 | 职责 | 用来回答 |
|---|---|---|
| 历年真题 | **考试行为证据**，最高优先级 | 考什么、怎么问、问多深、哪些知识换皮、哪些考点组合、哪些看似重要实际不考 |
| 教材 | **知识完整性来源** | 补正式定义、完整条件、公式、原理、推导、边界、规范术语；校验真题背后的理论依据 |
| 考试大纲 | **范围边界** | 约束"能不能考"；只有大纲能证明某知识超纲 |
| 个人笔记 | **用户视角的补充** | 口诀、易错记录、自己的理解——融入对应考点的人话解释与 tip 块；同时反映用户薄弱环节，相关考点可适当加重 |

关键区别：大纲约束"能不能考"，真题反映"实际上怎么考"。教材决定"知识从哪来"，但不决定"什么进笔记"——**进笔记的资格由考试决定**。个人笔记与教材/真题冲突时按 §13 处理，并向用户指出。

## 2. 素材不足时的降级路径

| 情况 | 处理 |
|---|---|
| 真题 ≥ 5 套 | 完整流程：频率统计、评级 S–D、趋势观察均可做 |
| 真题 2–4 套 | 正常反推考点，但**不做趋势结论**，评级只标 S/A/B，倾向保守 |
| 真题 1 套 | 真题只用于"确定题型和深度"，考点框架改由大纲+教材章节承担，所有考点标低置信 |
| 完全无真题 | 纯大纲+教材模式。不做重要度评级（禁止凭空标 S/A），笔记按知识体系组织 |
| 真题无答案/解析 | 先自行解题（可网络检索核对），在拆解记录中标注"答案为自行求解" |
| 真题是扫描件/图片 | 先转录为文本并逐题核对，转录稿存入工作目录 |
| 无大纲 | 只依据真题；"超纲/非重点"标签一律禁止使用 |
| 素材为 PDF | 先经 MinerU 解析为 Markdown（`scripts/parse_pdf.py`，需 `MINERU_API_KEY`），**抽查公式/表格识别质量**后再当文本用；扫描件加 `--ocr` |

## 3. 真题拆解

每一道题都要拆，不是只记题目和答案。每题一条记录：

```text
年份 / 题号 / 题型 / 主考点 / 次考点 / 解题动作 / 涉及公式定理 / 题目关键词 / 难度 / 分值 / 是否综合题 / 是否重复
```

例：

```text
2024 第15题
主考点：Cache地址映射与划分
次考点：地址划分
解题动作：求 Tag / Index / Offset
题型：计算题　分值：10
```

拆解结果**写入 `distill/papers.md`**（每题一小节），这是后续聚类和验证的依据，不要只留在对话里。

## 4. 反推考点：题 ≠ 考点

不要把题号当考点。多道表面不同的题可能共享同一底层知识结构：

```text
2022 求地址划分 ┐
2023 求映射位置 ├→ 共同知识：Cache地址映射与地址划分
2024 判断命中   ┘
```

判断标准：**不同题目背后的共同知识结构是什么？** 能用一句"考点名"概括的，合成一个考点。

## 5. 考点聚类

聚类同时考虑四个相似性：

```text
知识相似性 + 解题动作相似性 + 题型相似性 + 考试语义相似性
```

**不要只按教材章节分类。** 教材分两章的内容，真题可能一道题同时考，此时应合并为一个考点（如"地址结构与层次化存储系统"）。必要时建立"主考点 + 次考点"。

聚类结果写入 **`distill/topics.md`（考点登记表）**：每个考点一节，含定义、来源真题、频率统计、评级。

## 6. 频率统计与重要度评级

每个考点统计：出现年份、次数、连续出现情况、题型数、分值、是否综合题、是否有不同问法。

评级（内部优先级）：

```text
S 核心高频　A 重要　B 常规　C 低频　D 仅了解
```

评级因子：频率 + 近年趋势 + 分值 + 题型稳定度 + 覆盖面 + 综合题参与度。**不是出现次数越多越重要**：

- 连续 3 年出现 > 过去 10 年零星 3 次
- 出现 2 次每次 15 分 ≥ 出现 5 次每次 1 分
- 趋势表述只用"近年出现……""样本中观察到……"，**禁止"以后一定会……"**；样本不足以判断趋势时就不写趋势。

## 7. 频率不是删除依据

```text
高频 → 重点展开　　中频 → 正常整理
低频 → 压缩整理　　明确超纲（需大纲支持）→ 不纳入核心
```

低频考点不能直接删：可能是课程基础、综合题零件、或轮换出现。

## 8. 题型分析与变形识别

对每个考点回答："它以什么形式考？"——列出题型 A/B/C/D……

重点识别变形：**题目表面不同，底层解法相同**（直接问定义 → 给例子判断 → 场景题 → 综合计算）。这是"同一考点 + 四种考试表达"，不是四个知识点。

对重复题型抽象出**题型模型**（不是答案）：

```text
【题型】【输入】【要求】【核心知识】【解题流程①②③】【常见变形】【易错】
```

建立**信号提取表**（考试最重要的检索机制）：

```text
【题目出现】"按字节编址"
【想到】地址是字节地址
【下一步】按地址位数和容量算地址空间
```

理科课程用"解题流程"，记忆型课程（法学、历史等）的题型模型替换为**答题模板 + 得分点清单**。

## 9. 回教材补知识：按考法定深度

只补"理解/解决这个考点所必需"的教材知识，不搬整章。深度由真题决定：

| 真题要求 | 补充内容 |
|---|---|
| 识别 | 定义、核心区别、典型例子、易错点 |
| 计算 | 公式、变量含义、计算步骤、单位、边界 |
| 证明 | 定理、证明思路、证明模板、关键前提 |
| 综合应用 | 前置知识、知识链、场景识别、完整解题流程 |

## 10. 综合题拆解

综合题（CPU + Cache + 主存……）必须拆成：主考点 / 依赖知识 / 辅助知识，并识别**哪部分真正决定得分**。拆出的各部分归入各自考点，不单独留"综合题"条目。

## 11. 知识分层

```text
【核心考点】真题直接反复考查
【支撑知识】没单独考，但理解核心考点必需
【背景知识】教材有，对解题作用有限 → 大幅压缩或舍弃
```

笔记 = 核心考点 + 必要支撑知识。

## 12. 负证据

"多年未考"≠"不重要"。区分"多年未出现"与"完全超纲"——只有大纲或明确考试资料支持才能标"非重点"，否则标【低频】保留。

## 13. 教材与真题冲突

依次检查：是否考的不同语境/定义 → 教材版本与真题年份 → 保留课程真实考试语境。**不为迎合真题修改正式定义**，分三条并列：

```text
【考试口径】……　【教材严格定义】……　【注意】……
```

## 14. 防过拟合

笔记不是"2021 问什么、2022 问什么"的流水账——那只能押题，不能迁移。目标是：历年题目 → 抽象共同知识 → 题型模型 → 覆盖变形。

## 15. 篇幅按考试价值分配

```text
高频+高分+易错 → 展开        高频+基础 → 精炼
低频 → 简要覆盖              背景 → 大幅压缩
```

禁止平均分配篇幅。

## 16. 网络检索规则

教材资料缺口可以上网检索（定义、公式、术语、典型例题），但必须遵守：

1. 教材/大纲材料优先；网络内容用于**核对和补缺**，不替代用户提供的教学材料。
2. 关键结论（定义、公式）至少两个来源一致才采用；不一致 → 标【存疑】并说明分歧。
3. **禁止把检索到的一般性知识包装成"教材原文"或"大纲要求"。**
4. 检索结果记入笔记时只写知识本身，不写 URL 水文。

## 17. 验证闭环（必须执行）

笔记完成后，拿真题**回测**：

```text
□ 每道重要真题都能定位到某个考点？
□ 每道真题都能从笔记找到解题依据？
□ 真题要求但笔记没覆盖的知识？（有 → 补）
□ 笔记内容从未在真题出现？（判断是核心/支撑知识则保留，否则压缩）
```

建立**覆盖矩阵**（`distill/coverage.md`）：行=真题（年+题号），列=考点，交叉打勾，检查"真题→考点"与"考点→真题"双向覆盖。

最后自检六问：

```text
考试覆盖：真题主要知识全覆盖了吗？
考点抽象：有没有把底层相同的题错拆成多个考点？
题型覆盖：一个考点的不同问法都覆盖了吗？
解题能力：学生只看这个考点，能做出对应真题吗？
反向验证：能从笔记解释每道重要真题为什么这么做？
压缩程度：对考试无帮助的教材内容删够了吗？
```

## 18. 最终目标

三层结构：**考点地图 → 考点知识 → 题型与真题**。学生复习时先看"考什么"，再看"知识是什么"，最后看"题怎么考"。

评价标准不是"教材总结得全不全"，而是：

> **这份笔记能不能最大限度解释历年真题，并让学生面对新题时能够迁移。**
