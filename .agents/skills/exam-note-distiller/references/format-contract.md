# 中间格式规范：exam-notes.md

本文件是"内容生产"与"页面渲染"之间的**唯一接口**。蒸馏阶段产出本格式；渲染阶段用 `scripts/render_notes.py`（其实现对应 `assets/template.html` 文件头注释里的渲染规则）以本格式为唯一内容源生成 index.html。这样内容修改不用碰 HTML，重新渲染也不用改内容。

一个课程一个文件，UTF-8 编码。文件名约定为 `exam-notes.md`。**它是课程的唯一内容源**：后续更新先改它，再重新渲染。

---

## 1. 文件头指令

文件最开头、第一个 `## ` 标题之前，是若干行 `key: value` 指令：

```
course: 02324 离散数学
subtitle: 全国自考 02324
github: https://github.com/xxx/xxx-mindmap
```

| 指令 | 必填 | 说明 |
|---|---|---|
| `course` | 是 | 课程名。用作页面大标题、导出文件名前缀 |
| `subtitle` | 否 | 副标题，显示在页头统计区（如"全国自考 02324"、"2025 期末总复习"） |
| `github` | 否 | 填了才显示右上角 GitHub 按钮 |
| `quiz` | 否 | 刷题网页 URL，右上角显示"刷题"胶囊入口（新标签页打开） |
| `mistakes` | 否 | 错题集 URL，右上角显示"错题集"胶囊入口，与"刷题"并排 |

## 2. 结构层级

只用三到四级标题，层级含义固定：

```markdown
## 第一章 命题逻辑            ← 章（H2）
### 考点1：命题符号化          ← 考点（H3）
meta: level=S; freq=2021、2022、2024
#### 1.1 是什么               ← 子主题（H4）
正文内容……
```

规则：

- **`## ` = 章**。既包括教材章节（`第一章 …`），也包括总览专题（见 §4）。
- **`### 考点N：名称` = 考点**。必须以 `考点` 开头带编号，全角半角冒号均可。编号不要求连续，但同一文件内唯一。
- **`meta:` 行 = 考点元数据**，写在考点标题的下一行。支持 `level`（S/A/B/C/D，重要度评级）和 `freq`（真题出现记录，自由文本）。可省略。
- **`#### ` = 子主题**。考点内部的内容一律组织成子主题，不要把正文直接裸写在考点标题下（裸写的内容会被挪到该考点所有子主题之后显示）。
- **不要使用 `# `（H1）**，渲染时忽略它。
- 章下、考点标题之前的正文会成为"章导语"，显示在章节卡片顶部展开区（适合放章节概述）。

## 3. 内容块

子主题（或章导语）下，逐行书写。**一行就是一个段落**，不要把多条内容挤在一行。

### 3.1 行内标记

- `**加粗**` → 关键结论、必背内容
- `==强调==` → 易错警告、口诀（渲染为醒目的强调色加粗）
- `` `代码` `` → 行内代码（码内容原样呈现，`**`/`==` 不再解析）。写 C 判等符、指针表达式等代码时**必须**用反引号包住：一行里出现两个裸 `==` 会被配对成一个 `==强调==`，等号凭空消失（历史教训：判空条件 head->next==head 曾被渲染成 head->nexthead）

### 3.2 公式块（```f）

一切公式、推导、复杂表达式**必须**放进公式块，禁止裸写在正文里：

````markdown
```f
P ∧ Q → R  ≡  ¬P ∨ (Q → R)
```
````

可多行，渲染为等宽字体、左侧章节色边线的代码风格块。

### 3.3 语义提示块（```err / ```tip / ```ok）

````markdown
```err
绝对不能把小数代入 N 和 Z！
```
```tip
题目出现"按字节编址"→ 地址表示字节地址。
```
```ok
单射 ⇔ 满射 ⇔ 双射（有限集、|D|=|C| 时）
```
````

- `err` 红色：易错点、常见错误
- `tip` 黄色：解题信号、记忆提示、口诀
- `ok` 绿色：正确做法、成立的结论

### 3.4 表格

标准 Markdown 管道表格，第一行是表头：

```markdown
| 操作 | 顺序表 | 链表 |
|---|---|---|
| 按序号访问 | O(1) | O(n) |
| 插入删除 | O(n) | O(1) |
```

对比型内容（方法对比、概念辨析、题型对比）优先用表格。

### 3.5 列表

`- ` 开头，每行一项。**不支持嵌套列表**——需要层级时改用多个子主题或表格。

### 3.6 图示块（```d）

结构类知识点的示意图（链表指针、树、环形队列、图的存储等）放在图示块里，内容是**完整的 `<svg>…</svg>`**，渲染器原样内嵌为 `<figure class="diagram">`：

````markdown
```d
<svg viewBox="0 0 320 70" width="320" height="70" xmlns="http://www.w3.org/2000/svg">
  <rect class="dg-box" x="10" y="20" width="34" height="28" rx="4"/>
  <text x="27" y="34" class="dg-t" text-anchor="middle" dominant-baseline="central">a₁</text>
  …
</svg>
```
````

写作规则：

- **配色禁止写死**：一律使用模板预置的 `dg-*` 类（`dg-box`/`dg-box2`/`dg-circ`/`dg-circ2` 主/次结点，`dg-t`/`dg-s`/`dg-lab`/`dg-hl` 文字，`dg-edge`/`dg-flow`/`dg-dash` 连线，`dg-head`/`dg-headf` 箭头，`dg-fill` 高亮底色，`dg-bad`/`dg-badt`/`dg-okt`/`dg-tipt` 红绿黄标注），深浅主题与章节色自动适配；模板的 Word 导出按计算样式把 SVG 栅格化，写死颜色会破坏主题。
- 文字元素统一带 `text-anchor="middle" dominant-baseline="central"`（按视觉中心定位，y 直接给中心坐标）。
- 给 `svg` 显式 `viewBox` 与 `width`/`height`（页面按 `max-width:100%` 缩放）。
- 前后各空一行；图前可加一行灰字说明读图要点（普通正文行）。
- 图只放讲解子主题里，不放真题/速记区块；一图说一件事，宽度控制在 720px 内。

### 3.7 树状速记块（```tree）

章级速记图（放在章导语里，"每章一图总览"）用树状块：内容是**缩进树文本**，2 个空格一级，渲染为带树线的速记图：

````markdown
## 第三章 栈和队列

章导语……

```tree
第三章 栈和队列（考点 15—21）
  核心：出栈序列、循环队列
  15. 栈的定义与出栈序列【S】
    仅允许在栈顶插入、删除；LIFO
    出栈序列模拟
      目标不在栈顶 → 继续入栈
      目标被压住 → 不可能
```
````

规则：

- 第一个 0 缩进行是**根节点**（章名胶囊），之后每个 2 空格行是一个分支（考点级胶囊），更深缩进是叶子；**层级只看前导空格数（÷2）**，不写 `│├└` 树线字符。
- 行内沿用 `**加粗**`、`==强调==`；行尾的 `【S】【A】【B】` 会自动转成重要度徽章。
- 以"易错"开头的节点自动标红，"口诀/【记忆】"开头自动标黄。
- 一章一图，放章导语末尾；图后可跟一个 ```tip 块放"做题方法"一句。
- 树文本要自足：公式、步骤、边界条件写在叶子上，不依赖正文。

## 4. 总览专题（特殊章节）

除了教材章节，文件末尾用同级 `## ` 章节放置全书总览层，渲染器会把它们当作普通章节卡片处理（同样可折叠）。约定按此顺序：

```markdown
## 考试地图        ← 放最前或最后均可，全书考点频率/题型/重要度总表
## 高频公式        ← 公式块集合，考前最后一遍
## 高频易错        ← err 块集合
## 题型索引        ← 考点 → 题型 对照表
## 考前速记        ← 压缩到一屏的终极速查
```

"考试地图"建议用表格：`| 考点 | 频率 | 题型 | 重要度 |`，并附"综合题常组合：A + D"之类一行结论。

## 5. 完整示例

````markdown
course: 数据结构
subtitle: 期末总复习

## 考试地图

| 考点 | 频率 | 题型 | 重要度 |
|---|---|---|---|
| 顺序表与链表 | 高频 | 算法设计/选择 | S |
| 二叉树遍历 | 高频 | 计算/画图 | S |

综合大题常组合：二叉树 + 递归。

## 第一章 线性表

本章真题集中在存储结构比较与算法设计题。

### 考点1：顺序表与链表的比较

meta: level=S; freq=2021、2022、2023、2024

#### 1.1 是什么

顺序表：**逻辑相邻的元素物理位置也相邻**。
链表：通过==指针==链接的结点序列。

#### 1.2 核心对比

| 操作 | 顺序表 | 链表 |
|---|---|---|
| 按序号访问 | O(1) | O(n) |
| 插入删除 | O(n) | O(1) |

#### 1.3 易错与口诀

```err
单链表插入必须先接后断：先连后继指针，再改前驱，顺序颠倒会断链。
```

```tip
【记忆】查多用表，插删多用链。
```

- 头插法建表：读入顺序与链表结点顺序==相反==。
- 尾插法需设尾指针。

## 高频公式

```f
比较次数：顺序查找 ASL = (n+1)/2
```
````

## 6. 常见错误

| 错误 | 后果 |
|---|---|
| 多条内容挤一行 | 渲染挤成一团 |
| 公式裸写正文 | 没有公式块样式，与普通文字混淆 |
| 用 `>` 引用块 | 渲染器不认识，按普通段落处理 |
| 嵌套列表 | 不支持，层级错乱 |
| 考点标题不带编号（`### 考点：X`） | 自动编号，但编号可能与你预期不一致 |
| 在 `## ` 之前写正文 | 被忽略 |
| 用 `**` 代替 `####` 做子主题 | 变成普通段落文字 |
