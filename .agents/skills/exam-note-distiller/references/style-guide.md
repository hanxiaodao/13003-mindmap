# 写作风格规范

方法论决定"写什么"，本文档决定"怎么写"。这是笔记好读好记的关键。

## 1. 考点粒度

一个考点 = **一道题背后的一个知识结构**，能独立出题、能独立复习。

- 太大（一章的内容、多个解题动作）→ 拆
- 太小（一条定义，从未单独出题）→ 并入相邻考点作子主题
- 一门课的考点总量参考：30–120 个。超过 120 → 检查是否把题型拆成了考点；少于 20 → 检查是否把章当成了考点。

## 2. 考点内部结构

子主题按固定骨架组织（`#### X.1` 编号与考点号对应），**按考法裁剪**——真题只考识别的考点不写"怎么计算"：

```markdown
#### X.1 是什么      正式定义 + 一句人话解释（两者都要）
#### X.2 必背        需要死记的结论/公式/清单
#### X.3 核心规则    判定条件、适用范围、前提
#### X.4 怎么判断    判定型题的判定流程
#### X.5 怎么算/证   计算步骤或证明模板
#### X.6 题目怎么换皮 同一考点的不同问法（来自变形识别）
#### X.7 易错点      err 块，一条一个坑
#### X.8 真题        "2024 第15题：考查……"证据列表
```

不是每个考点都要有全部八节。常见裁剪：纯记忆型考点 → 1/2/7/8；计算型 → 1/2/5/7/8。

## 3. 文风七条

1. **一句一个事实。** 一行写一条结论，不写"首先……其次……然后……"的长句。
2. **正式定义后面跟人话。** "格：任意两个元素都有唯一最小上界和最大下界（人话：任意挑两个，往上往下各有一条唯一的路）。"
3. **易错点用强标记。** 行内用 `==…==`（如"绝对不能代入小数！"），独立的坑用 ` ```err ` 块。易错点要写"错成什么样"而不只写"注意"。
4. **口诀用 ` ```tip ` 块，标【记忆】。** 只在真有压缩效果时用，不硬造顺口溜。
5. **公式一律 ` ```f ` 块**，每行一个推导步骤；正文里只提公式名。
6. **对比用表格，不用对仗段落。** 凡是"A 如何、B 如何"的内容，几乎都该是表格。
7. **结论尽量配最小例子。** 抽象规则后给一个一行的小例子锚定。

## 4. 术语与记号

- 每个概念给**教材规范术语**，括号给通俗别名。判断题按教材口径答，理解按人话记。
- 符号全篇统一：一个概念全笔记只用一个符号；集合、关系等符号在"高频公式"章节首次集中列出。

## 5. 真题证据格式

考点末尾"X.8 真题"用一行一题，写清"为什么值得复习"：

```markdown
#### 1.8 真题
2024 第15题：给定主存地址求 Cache 字段（计算型，10 分）
2022 第9题：判断映射是否命中（判断型）
```

**红线：年份、题号、考查内容只能来自拆解记录中真实存在的题目。** 记不清、材料里没有的，写【待核实】，禁止编造。

## 6. 篇幅基准

- S 级考点：15–40 行；A 级：10–25 行；B/C 级：5–15 行；D 级：1–3 行。
- 单个考点超过 60 行 → 考虑拆分；不足 3 行且无真题支撑 → 考虑合并。
- 全部考点写完后回头看一遍总行数分布：篇幅应与评级正相关，出现"C 级比 S 级还长"就是失衡。
