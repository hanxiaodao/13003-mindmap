考点1数据、数据元素与数据项S2024.10、2025.10、2026.04▼
1.1 是什么
数据：能被计算机处理的符号的集合（广义：数字、文字、图片、音频、视频）。
数据元素：数据的基本单位，一个元素表达一条完整信息（如成绩表中的一行）。
数据项：构成数据元素的、不可再分的最小单位（如一行中的"语文120分"）。
层级：数据 ⊃ 数据元素 ⊃ 数据项（整栋楼 ⊃ 一套房 ⊃ 一个房间） 1.2 怎么判断
  • "基本单位"→数据元素；"最小/不可再分"→数据项
  • 数据项不限于数值——广义数据包括一切可处理符号
  • 数据项之间有关联，不能叫"集合"（集合内元素无关联）

考点2逻辑结构与存储结构S2024.10、2025.04、2025.10、2026.04▼
2.1 四种基本逻辑结构
  • 集合：任意两元素间无任何关系（最简单）
  • 线性结构：一对一（链条状）
  • 树形结构：一对多（层次化，同层结点间不关联）
  • 图结构：多对多（网状，最复杂）
  • 两大类：线性结构 vs 非线性结构（集合、树、图统称非线性）
【记忆】限制越多结构越简单：集合（禁连）＜线性（单链）＜树（分叉）＜图（无限制）。 2.2 四种基本存储结构
  • 顺序存储：物理位置依次相邻（工具：数组）
  • 链式存储：物理可不连续，靠指针连接
  • 索引存储：像书的目录，先查索引缩小范围（非重点，了解）
  • 散列（哈希）存储：函数映射 h(key) 直接定地址
2.3 逻辑与存储的关系
  • 逻辑结构描述元素间关系，独立于存储方式，不涉及计算机实现
  • 基本操作的具体实现依赖存储结构（2025.04-18 填空原句）
链式存储"不要求连续"≠"一定不连续"——物理地址可连续也可不连续。 2.4 真题

考点4算法的特性与时间/空间复杂度S2024.10、2025.04、2025.10、2026.04▼
4.1 算法五特性（必背，考过解答题）
  • 输入：0 个或多个
  • 输出：至少 1 个
  • 有穷性：有限步骤后终止
  • 确定性：每步含义确切、无二义性
  • 可行性：每步都是基本运算、能精确实现
"把大象装冰箱"三步法不可行——缺可行性；指令有歧义——缺确定性。 4.2 时间复杂度
  • 度量的是语句执行次数（频度），不是运行时间——运行时间受软硬件影响，不可比
  • 大 O 规则：只取增长最快的主项，忽略系数与低阶项
执行总数 = n²/2 + n + 3 → O(n²) 常见阶（效率高→低）：O(1) ＞ O(log₂n) ＞ O(n) ＞ O(n log₂n) ＞ O(n²) ＞ O(2ⁿ) 比较阶数：设 n=10 代入求值（log₂10≈3.3 ＜ 10 ＜ 100 ＜ 1024）
  • O(1) 表示常数条语句（3 条、100 条都是 O(1)），不是"只有 1 条语句"
  • 时间复杂度只与问题规模 n 有关，与硬件、语言、编译器无关
  • 分析程序段：找循环（while/for），循环 n 次→O(n)
4.3 空间复杂度
算法运行中临时占用的辅助空间；与时间复杂度并列为算法分析的两大方面。

考点7顺序表——地址计算与随机存取S2024.10、2026.04▼
7.1 是什么
顺序表 = 线性表 + 顺序存储：数组实现，逻辑相邻物理相邻，下标 0~n-1，可随机存取（直接算地址）。
7.2 地址公式
LOC(aᵢ) = LOC(a₀) + i × d （d = 每个元素占的存储单元数） 第 i 个与第 j 个元素相隔 |i−j| 个元素——间隔直接序号相减，不用逐个数 7.3 怎么算
  • 2026.04 真题：a[8] 地址 100、每元素 4 单元 → a[11] = 100+(11−8)×4 = 112
  • 2024.10 真题：第 1 个元素地址 100、每元素占 8 单元 → 第 6 个元素（a₅）末单元 = 100+5×8+8−1 = 147
下标从 0 开始：第 6 个元素是 a₅ 不是 a₆；问"最后一个存储单元"要 加长度−1，不是首地址。
  • O(1) 的操作：按地址访问第 i 个元素、求第 i 个元素直接前驱；插入、删除都不是 O(1)

考点9单链表结构与判空S2024.10、2025.10、2026.04▼
9.1 是什么
单链表 = 线性表 + 链式存储。结点 = 数据域 + 指针域；尾结点指针域为空（∧）。
  • 头结点：链表最前、不存实际数据的辅助结点；首结点：第一个存数据的结点
  • 头指针 head：指向头结点（不带头结点时指向首结点）；单链表由头指针标识（不能只用尾指针）
  • 尾结点判定：p->next == NULL
9.2 必背判定

考点10单链表插入/删除的指针操作S2024.10、2025.10、2026.04▼
10.1 插入：先接后断
在 p 与其后继之间插入 s 所指结点：
s->next = p->next; // 第一步：先接后继 p->next = s; // 第二步：再接前驱
  • 若前后两结点都有独立指针：两步顺序可颠倒
  • 后继只能经 p->next 访问时：顺序绝不可颠倒，否则断链、丢失后继结点
10.2 删除：跨过被删结点
删除 p 的后继结点 q：
p->next = q->next; // 前驱跨过 q（即 p->next = p->next->next） free(q); // 释放结点空间，防止内存泄漏 10.3 算法阅读常见问法
  • 说明功能：将首结点移到表尾（2025.04-30）；相邻结点两两交换（2026.04-20）
  • 按位序插入：定位到第 i 个结点 p 后，s->next=p->next; p->next=s（2025.10-30）
C 语言：= 是赋值，== 才是判断相等。算法阅读题看错等号，功能全错。 10.4 真题

考点11循环链表与双向链表B2025.04▼
11.1 循环链表
尾结点指针域回指头结点（不再置空）；优点：从任一结点出发可遍历全表。
判空（带头结点）：head->next == head p 是尾结点 ⇔ p->next == head 11.2 双向链表
结点三域：prior（前驱）+ data + next（后继）；可直接找前驱。
对称性（常考等式）：
p = p->prior->next = p->next->prior 双向循环链表：头结点 prior 指向尾结点、尾结点 next 指向头结点；判空：head->nexthead 且 head->priorhead。

考点12静态链表B2024.10▼
12.1 是什么
用数组保存的链表：下标即地址，用游标（存下一结点的下标）代替指针。
  • 头结点数据域可复用存元素个数；尾结点游标存 −1 表示结束
  • 单循环链表的数组表示：尾游标指向头结点下标 0（而不是 −1）
  • 双向链表需三列（数据+前驱+后继），一般不考
12.2 怎么判断链表类型
从游标逐个跳转还原：末尾指向 −1→单链表；末尾指向 0→单向循环链表；仅两列→排除双向。

考点14线性表算法——双指针原地划分S2024.10、2025.10、2026.04▼
14.1 题型模型
  • 输入：顺序表/数组
  • 要求：原地（O(1) 辅助空间）把元素按条件分两边，或删除某类元素
  • 解法①：i 从左、j 从右双向扫描，不符合者交换（划分型）
  • 解法②：i 读、j 写快慢指针，把保留的元素依次前移，最后更新表长（过滤型）
14.2 典型真题

  • 2025.10 第34题（设计，10分）：负数放非负数前面 → 双指针交换划分，(−1,−2,3,1,−3,5)→(−1,−2,−3,1,3,5)
  • 2026.04 第21题（问答）：奇数移到偶数前面 → {1…8}→{1,3,5,7,2,4,6,8}

考点36哈夫曼树、WPL 与哈夫曼编码A2025.10▼
36.1 概念链
  • 路径长度：根到该结点经过的边数；权：给结点赋的数值
  • 叶结点的带权路径长度 = 权 × 路径长度
  • WPL：二叉树所有叶结点的带权路径长度之和
  • 哈夫曼树：n 个带权叶构造的所有二叉树中 WPL 最小者；不唯一（等权或左右交换都不改变 WPL）
哈夫曼树的定义是"WPL 最小"，不是"权值和最小"，也不是"高度最低"。 36.2 构造方法
每次取权值最小的两棵树合并，新结点权=两者之和；重复直到只剩一棵。n 个叶合并 n−1 次。
n 个叶结点的哈夫曼树：总结点数 = 2n − 1；分支结点数 = n − 1 （哈夫曼树中没有度为 1 的结点） 例：权 {1,3,5,7}：1+3=4 → 4+5=9 → 7+9=16；WPL = 7×1 + 5×2 + (1+3)×3 = 29。
36.3 哈夫曼编码
字符作叶、出现频率作权；左分支标 0、右分支标 1；根到叶的路径 0/1 序列即该字符编码。
  • 哈夫曼编码是前缀码：任一编码都不是其他编码的前缀 → 译码无歧义
判断一组编码是否可能：只要出现"某编码是另一编码的前缀"（如 1 是 10、100 的前缀）→ 不可能。 36.4 真题

考点46交换排序（起泡 + 快速）A2024.10、2025.10▼
46.1 起泡排序
相邻元素比较，逆序交换；每趟把当前最值"冒"到一端；n−1 趟；某趟无交换可提前结束。
  • 稳定；比较次数固定 n(n−1)/2（与数据无关）
  • 特征：每趟确定一个最值，末尾（或首部）若干元素有序
  • 例：6 个元素降序起泡 → 比较 6×5/2=15 次（2024.10-24）

  • 平均 O(n log₂n)、最坏 O(n²)（初始基本有序时）；不稳定；空间 O(log₂n)（递归栈）

55.1 定义（左小右大）

别名：二叉排序树、二叉搜索树、二叉查找树（同一概念）。

  • 填值推理：按左右子树结点个数定根（左子树 k 个 ⇒ 根是第 k+1 小的值），逐层推理

顺序表地址：LOC(aᵢ) = LOC(a₀) + i×d 二维行主序：LOC = 首址 + (i×n + j)×d 列主序：LOC = 首址 + (j×m + i)×d 顺序表平均移动：插入 n/2 次；删除 (n−1)/2 次；删第 i 个移动 n−i 个 循环队列：入队/出队 (x+1)%m；判空 front==rear；判满 (rear+1)%m==front； 元素个数 (rear−front+m)%m 三角/对称矩阵存储量：n(n+1)/2 串的子串数：n(n+1)/2 + 1；BF 最坏比较 (n−m+1)×m 二叉树：第 i 层最多 2ⁱ；高度 h 最多 2ʰ−1；n0 = n2 + 1；卡特兰数 C(2n,n)/(n+1) 完全二叉树：n 个结点高度 ⌊log₂n⌋+1；哈夫曼树总结点 2n−1，分支结点 n−1 图：无向 Σ度=2e；有向 Σ入度=Σ出度=e；完全图 n(n−1)/2（有向 n(n−1)）；连通最少 n−1 条边 最小生成树：n−1 条边；拓扑排序（邻接表）O(n+e) 排序：起泡/简单选择比较次数 n(n−1)/2（固定）；折半判定树高度 ⌊log₂n⌋+1 查找：顺序成功 ASL=(n+1)/2、不成功 ASL=n；AVL 最少结点 N(h)=N(h−1)+N(h−2)+1
高频易错▼
单链表插入必须先接后断：s->next=p->next 再 p->next=s，顺序颠倒会断链丢后继。 链式存储"不要求连续"≠"一定不连续"；= 是赋值、== 才是判等；判空 head->next==NULL（带头结点）/ head==NULL（不带头）。 循环队列容量陷阱：数组下标 0~m 时容量是 m+1；判空判满都用双等号；rear 指向约定变了公式跟着变。 广义表表尾永远是"表"要套括号：Tail((c,d))=(d) 不是原子 d；表头表尾对子表要重新识别。 n0 = n2 + 1 与 n1 无关——题目给 n1 多半是干扰条件；"二叉树的度为 2"错，是"不超过 2"。 顺序栈先移指针还是先存元素，取决于 top 指向空位还是栈顶元素；两道真题（2025.10-6、2026.04-6）都考这个。 哈夫曼编码判"不可能"：某编码是另一编码的前缀（如 1 是 10 的前缀）即不可能；哈夫曼树不唯一。 存储结构三连辨析：最短路径用 Dijkstra；最小生成树用 Prim/Kruskal；WPL 最小是哈夫曼树。 折半查找两个前提缺一不可：顺序存储 + 有序；偶数个元素取前半段最后一个作 mid。 希尔排序、简单选择、快速、堆排序不稳定；稳定的是直接插入、起泡、归并、基数（插冒归基）。

考前速记▼
  • 四种逻辑结构：集合、线性、树、图；四种存储：顺序、链式、索引、散列
  • 算法五特性：输入(≥0)、输出(≥1)、有穷、确定、可行
  • 出栈序列数 = 卡特兰数 C(2n,n)/(n+1)；p₁=n ⇒ 第 i 个出栈 = n−i+1
  • 单链表插入：先接后断；判空：带头 head->nextNULL，不带头 headNULL
  • 循环队列：个数 (rear−front+m)%m，判满 (rear+1)%m==front
  • 二维数组：行主序 (i×n+j)×d，列主序 (j×m+i)×d；子串数 n(n+1)/2+1
  • 广义表：表尾是表要套括号；长度看最外层，深度看括号层数
  • 二叉树：n0=n2+1；中序+先序（或后序）唯一确定；树的先序=对应二叉树先序，树的后序=对应二叉树中序
  • 哈夫曼：WPL 最小、不唯一、2n−1 个结点、前缀码
  • 图：无向 Σ度=2e，有向 Σ入度=Σ出度=e；DFS 用栈、BFS 用队（每点入队 1 次）；生成树 n−1 条边
  • 排序稳定口诀：插冒归基稳，选希快堆不稳；O(nlogn) 且稳定只有归并；一趟未必归位的是直接插入
  • 折半查找：顺序存储+有序；最多比较 ⌊log₂n⌋+1；BST 中序遍历升序；分块查找块间有序
  • 哈希：除留余数选质数；冲突=不同关键字同地址；线性探测+1 顺次、二次探测±i²、链地址拉链
