  • 第一章 绪论（考点 1—5）
    • 核心：基本概念、数据结构、算法分析
    • 1. 数据、数据元素与数据项
      • 数据：能被计算机处理的符号集合
      • 数据元素：构成数据的基本单位，表达一个完整对象
      • 数据项：构成数据元素的最小、不可再分单位
      • 层级：数据 ⊃ 数据元素 ⊃ 数据项
        • 题干关键词："基本单位"→元素；"最小单位"→数据项
    • 2. 逻辑结构与存储结构A
      • 四种逻辑结构
        • 集合：元素间没有逻辑关系
        • 线性：一对一
        • 树：一对多
        • 图：多对多
      • 四种存储结构
        • 顺序：物理地址连续
        • 链式：依靠指针连接
        • 索引：借助索引定位数据
        • 散列：h(key) 计算存储地址
      • 逻辑结构描述"元素间是什么关系"
      • 存储结构描述"元素在内存中如何组织"
      • 易错：链式存储不要求地址连续 ≠ 地址一定不连续；操作的具体实现依赖存储结构
    • 3. 抽象数据类型 ADT
      • 三要素：数据对象 + 数据关系 + 基本操作
      • 描述类型的逻辑特性与操作
      • 定义 ADT 不等于编写操作的具体实现
    • 4. 算法五特性S
      • 输入：0 个或多个
      • 输出：至少 1 个
      • 有穷性：有限步骤后终止
      • 确定性：每个步骤含义明确，无歧义
      • 可行性：每一步都能精确执行
      • 易错：有穷性≠高效；确定性≠可行性
    • 5. 算法设计策略与复杂度S
      • 六种策略
        • 递推：已知小规模解 → 推出大规模解
        • 迭代：反复更新当前值
        • 递归：函数调用自身，依赖调用栈
        • 贪心：每一步选择当前最优（例：Prim、Kruskal、哈夫曼）
        • 分治：分解 → 解决 → 合并（例：归并、快速排序）
        • 动态规划：重叠子问题 + 最优子结构
      • 时间复杂度
        • 分析语句执行次数随问题规模 n 的增长
        • 大 O：保留最高阶项、忽略常数系数（n²/2+n+3 → O(n²)）
        • 常见增长：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)
        • 循环 n 次通常 O(n)；两层嵌套 n×n 通常 O(n²)
      • 空间复杂度
        • 统计随 n 增长的辅助空间
        • 固定数量变量 → O(1)
        • 保存 n 个元素的辅助数组 → O(n)
【做题】先判断题目问的是逻辑结构、存储结构还是算法特性；算复杂度先统计执行次数再保留最高阶项。O(1) 不是"只有一条语句"，而是执行开销不随 n 增长。

考点2逻辑结构与存储结构S2024.10、2025.04、2025.10、2026.04▼
2.1 四种基本逻辑结构
  • 集合：任意两元素间无任何关系（最简单）
  • 线性结构：一对一（链条状）
  • 树形结构：一对多（层次化，同层结点间不关联）
  • 图结构：多对多（网状，最复杂）
  • 两大类：线性结构 vs 非线性结构（集合、树、图统称非线性）
【记忆】限制越多结构越简单：集合（禁连）＜线性（单链）＜树（分叉）＜图（无限制）。 2.2 四种基本存储结构
  • 顺序存储：物理位置依次相邻（工具：数组）
  • 链式存储：物理可不连续，靠指针连接
  • 索引存储：像书的目录，先查索引缩小范围（非重点，了解）
  • 散列（哈希）存储：函数映射 h(key) 直接定地址
2.3 逻辑与存储的关系
  • 逻辑结构描述元素间关系，独立于存储方式，不涉及计算机实现
  • 基本操作的具体实现依赖存储结构（2025.04-18 填空原句）
链式存储"不要求连续"≠"一定不连续"——物理地址可连续也可不连续。 2.4 真题

3.1 是什么
抽象数据类型（ADT）：自定义的类型 + 该类型上的操作；只描述逻辑特性，不涉及具体实现。

  • 定义 ADT 只需：给类型名字、定义操作、描述元素——不需要实现操作

考点4算法的特性与时间/空间复杂度S2024.10、2025.04、2025.10、2026.04▼
4.1 算法五特性（必背，考过解答题）
  • 输入：0 个或多个
  • 输出：至少 1 个
  • 有穷性：有限步骤后终止
  • 确定性：每步含义确切、无二义性
  • 可行性：每步都是基本运算、能精确实现
"把大象装冰箱"三步法不可行——缺可行性；指令有歧义——缺确定性。 4.2 时间复杂度
  • 度量的是语句执行次数（频度），不是运行时间——运行时间受软硬件影响，不可比
  • 大 O 规则：只取增长最快的主项，忽略系数与低阶项
执行总数 = n²/2 + n + 3 → O(n²) 常见阶（效率高→低）：O(1) ＞ O(log₂n) ＞ O(n) ＞ O(n log₂n) ＞ O(n²) ＞ O(2ⁿ) 比较阶数：设 n=10 代入求值（log₂10≈3.3 ＜ 10 ＜ 100 ＜ 1024）
  • O(1) 表示常数条语句（3 条、100 条都是 O(1)），不是"只有 1 条语句"
  • 时间复杂度只与问题规模 n 有关，与硬件、语言、编译器无关
  • 分析程序段：找循环（while/for），循环 n 次→O(n)
4.3 空间复杂度
算法运行中临时占用的辅助空间；与时间复杂度并列为算法分析的两大方面。

考点5算法设计策略A2025.04、2026.04▼
5.1 六种基本策略（大纲要求"领会"）
  • 递推法：由规模 1…i-1 的一系列解构造规模 i 的解（典型：斐波那契数列存数组）
  • 迭代法：反复用新值更新旧值逼近解
  • 递归法：函数直接或间接调用自身（底层靠栈）
  • 贪心法：每步选当前最优（典型：Prim、Kruskal、哈夫曼、迪杰斯特拉）
  • 分治法：分—治—合（典型：归并排序、快速排序、折半查找）
  • 动态规划法：最优子结构 + 重叠子问题

第二章 线性表9考点▼
本章真题集中在顺序/链式存储对比、单链表指针操作与"双指针"算法设计；单链表插入"先接后断"是全场第一易错点。
本章速记图：
  • 第二章 线性表（考点 6—14）
    • 核心：地址计算、指针操作、特殊链表、双指针算法
    • 6. 线性表的定义与特点
      • n(n≥0) 个数据元素组成的有限序列；空表 n=0
      • 首元素无直接前驱；末元素无直接后继
      • 有序表：元素值按位置递增或递减；无序表：不满足
    • 7. 顺序表：地址计算与随机存取S
      • 数组实现，逻辑相邻 ⇒ 物理相邻；下标从 0 起
      • LOC(a[i]) = LOC(a[0]) + i×d
      • 任意起点：LOC(a[i]) = LOC(a[k]) + (i−k)×d
      • 第 i 个元素的末单元地址 = 首地址 + (i−1)×d + d−1
      • 易错：第 6 个元素从 0 编号是 a[5]；随机访问 O(1)，中间插删 O(n)
    • 8. 顺序表插入、删除
      • 插入：插入点起元素后移；n 个元素有 n+1 个可插位置；插到第 i 位移动 n−i+1 个
      • 删除第 i 个：后续前移，移动 n−i 个
      • 等概率平均：插入 n/2 次；删除 (n−1)/2 次
      • 插入/删除 O(n)；表尾插删是特例，可 O(1)
    • 9. 单链表结构与判空S
      • 结点 = 数据域 + next 指针域；头指针 head 指向链表起始
      • 头结点：辅助结点，不存数据；首结点：第一个数据结点
      • 带头结点判空 head->next==NULL；不带头判空 head==NULL
      • 尾结点判定：p->next==NULL
    • 10. 单链表插入与删除S
      • 在 p 后插入 s：① s->next=p->next ② p->next=s（先接后继，再接前驱）
      • 删除 p 的后继 q：① p->next=q->next ② free(q)
      • 易错：覆盖唯一的后继指针会断链；还要检查位置合法、结点非空
    • 11. 循环链表与双向链表
      • 单向循环链表：尾结点 next 指回头结点；判空 head->next==head；尾判定 p->next==head
      • 双向链表：prior+data+next；p == p->prior->next == p->next->prior
      • 双向循环链表：首结点 prior 指尾、尾结点 next 指头；空表两者都指自己
    • 12. 静态链表
      • 用数组存结点，游标（下一结点下标）代替指针
      • 尾游标 −1 → 普通静态单链表；尾游标指头下标 → 静态循环链表
      • 做题：从头结点下标出发沿游标追踪，不能按数组下标顺序读
    • 13. 顺序表与链表比较S
      • 顺序表：地址连续、随机存取 O(1)、中间插删 O(n)、无指针开销
      • 链表：地址不要求连续、访问 O(n)、定位后插删 O(1)、有指针开销
      • 选择：查找多、插删少 → 顺序表；插删多、长度变化大 → 链表
    • 14. 线性表双指针原地算法S
      • 目标：原地划分 / 删除指定类型元素
      • 划分型：i 左扫、j 右扫，放错侧就交换（不保证稳定）
      • 过滤型：i 读、j 写，符合条件前移，最后更新表长（保相对次序）
      • 易错：只移动数据不够，还必须更新表长

考点15栈的定义与出栈序列S2024.10、2025.04、2025.10、2026.04▼
15.1 是什么
栈：仅允许在一端（栈顶）插入和删除的受限线性表。先进后出 FILO / 后进先出 LIFO（同义）。

  • 形象模型：有底的桶、一摞盘子——底部元素被压住，只能等上面全走
  • 栈是"受限的线性表"（逻辑结构），存储结构未定
图示：栈只有栈顶一个出入口，后进的压在上面、先出。
15.2 出栈序列判断法（核心考法）
按目标序列依次模拟：要出的元素不在栈顶时，把它之前的元素全部压栈；压不出来（被压住）→该序列不可能。
  • n 个元素依次进栈，可能的出栈序列数 = 卡特兰数 C(2n,n)/(n+1)
  • p₁=n（最后元素先出）⇒ 剩余元素逆序输出，第 i 个出栈元素 = n−i+1
  • 最小栈容量：模拟全程，记录栈内同时最多的元素个数
【信号】"入栈序列+出栈序列"→模拟法；"p₁=n"→后面逆序；"最小容量"→数栈内峰值。 例：入栈1,2,3,4、出栈2,4,3,1：1入2入出2、3入4入（栈内1,3,4共3个）→最小容量3。 15.3 易错

考点18循环队列S2025.04、2025.10、2026.04▼
18.1 为什么需要循环队列
顺序队列的"假溢出"：rear 到数组末尾但前面还有空位；循环队列让指针回绕（取模）复用空间。
约定（本课口径）：front 指向队头元素，rear 指向队尾元素的下一个空位，容量 m。
18.2 三大公式（必背）
入队：rear = (rear + 1) % m 出队：front = (front + 1) % m 判空：front == rear 判满：(rear + 1) % m == front ← 牺牲一个单元区分空/满 元素个数：(rear − front + m) % m ← 统一公式，分界情况也适用 图示：循环队列——下标走到底取模回绕，rear 与 front 之间留一个空位作"牺牲单元"区分空/满。
18.3 易错
数组下标 0~m 时容量是 m+1 不是 m——入队语句应为 (rear+1) % (m+1)。判空用双等号 ==，单等号是赋值。 front/rear 约定改变公式随之变：rear 指向队尾元素本身时，入队是"先加再存"。 手算例：容量 6、front=3、rear=0，元素在下标 3、4、5；删 1 个入 2 个 → front=4、rear=2。

考点24广义表：长度、深度、表头表尾S2024.10、2025.04、2025.10▼

  • 长度：最外层元素个数（去掉最外层括号按逗号数；子表整体算 1 个）

  • 表尾 Tail(G)：去掉第一个元素后，剩余元素组成的广义表——结果永远是表，要套括号

从外往里逐步算，每步结果重新识别头尾。
例：A=(a,b,(c,d),(e,(f,g)))：Tail(A)→(b,(c,d),(e,(f,g)))；再 Tail→((c,d),(e,(f,g)))；Head→(c,d)；Tail((c,d))→(d)；Head→d。

26.1 是什么

26.2 BF 算法（朴素匹配）
主串指针逐位置尝试；一旦失配，主串指针回溯、模式串从头再来。

26.3 KMP 的思想（大纲"简单应用"）
用特征向量（next 数组）预先记录模式串自身的部分匹配信息；失配时主串指针不回溯，模式串滑到 next 指示的位置继续比较。

    • 32. 由遍历序列还原二叉树
      • 先序+中序 → 唯一；中序+后序 → 唯一；先序+后序 → 不能唯一
      • 步骤：①先序首元（后序末元）定根 ②中序定位根分左右 ③按子树长度划分另一序列 ④递归
      • 易错：两序列划出的子树长度必须一致
    • 33. 堆
      • 堆 = 完全二叉树 + 堆序性；大根堆父≥孩子，小根堆相反；兄弟无约束
      • 0-based：parent(i)=⌊(i−1)/2⌋；left=2i+1；right=2i+2
      • 建堆：从最后一个非叶结点向上调整
      • 插入：末尾插入 → 自下而上调整；删堆顶：末元素补根 → 自上而下调整
    • 34. 树、森林与二叉树的转换
      • 树→二叉树：第一个孩子作左孩子，兄弟依次串为右孩子
      • 二叉树→树：右孩子链还原为兄弟
      • 森林→二叉树：第一棵作左子树，其余依次沿右孩子连
      • 3 棵树（m₁、m₂、m₃）：转换后根的右子树结点数 = m₂+m₃
    • 35. 树与森林的遍历
      • 树没有中序遍历
      • 树先序 = 对应二叉树先序；树后序 = 对应二叉树中序
      • 森林同理：后序森林 = 对应二叉树的中序
    • 36. 哈夫曼树、WPL 与哈夫曼编码S
      • 路径长度 = 根到结点经过的边数；WPL = Σ(叶权值×路径长度)
      • 构造：每次取权值最小的两棵合并，新权 = 和；重复到剩一棵
      • n 个叶：合并 n−1 次、分支结点 n−1、总结点 2n−1
      • 编码：根到叶路径，左 0 右 1
      • 前缀码：任一编码不能是另一编码的前缀，出现前缀关系即不合法
【做题】结点数题优先用 n₀=n₂+1；遍历序列题先定位根；堆题按层序画树检查父子；哈夫曼题每次合并两个最小权值，最后算全部叶子的带权路径长度。

  • 满二叉树：每一层结点数都取最大值（层层全满）
  • 完全二叉树：除最后一层外各层全满，最后一层结点从左到右连续排列（不许跳空）

考点36哈夫曼树、WPL 与哈夫曼编码A2025.10▼
36.1 概念链
  • 路径长度：根到该结点经过的边数；权：给结点赋的数值
  • 叶结点的带权路径长度 = 权 × 路径长度
  • WPL：二叉树所有叶结点的带权路径长度之和
  • 哈夫曼树：n 个带权叶构造的所有二叉树中 WPL 最小者；不唯一（等权或左右交换都不改变 WPL）
哈夫曼树的定义是"WPL 最小"，不是"权值和最小"，也不是"高度最低"。 36.2 构造方法
每次取权值最小的两棵树合并，新结点权=两者之和；重复直到只剩一棵。n 个叶合并 n−1 次。
n 个叶结点的哈夫曼树：总结点数 = 2n − 1；分支结点数 = n − 1 （哈夫曼树中没有度为 1 的结点） 例：权 {1,3,5,7}：1+3=4 → 4+5=9 → 7+9=16；WPL = 7×1 + 5×2 + (1+3)×3 = 29。
图示：权 {1,3,5,7} 的哈夫曼树——叶子是圆、合并出的结点是方块，左边标 0 右边标 1。
36.3 哈夫曼编码
字符作叶、出现频率作权；左分支标 0、右分支标 1；根到叶的路径 0/1 序列即该字符编码。
  • 哈夫曼编码是前缀码：任一编码都不是其他编码的前缀 → 译码无歧义
判断一组编码是否可能：只要出现"某编码是另一编码的前缀"（如 1 是 10、100 的前缀）→ 不可能。 36.4 真题

    • 37. 图的基本概念与顶点度数S
      • 图 = 顶点集 + 边集；无向边无方向，有向弧尾→弧头
      • 无向图 Σ度 = 2e；有向图 Σ入度 = Σ出度 = e；顶点总度 = 入度+出度

      • 邻接矩阵 n×n：无向对称、1 的个数 = 2e；有向 1 的个数 = e
      • 无向图顶点度 = 该行 1 的个数；有向行和=出度、列和=入度

      • DFS：能深则深、无路回溯；栈或递归实现
      • BFS：先访问起点全部邻接点再逐层；队列实现，每点最多入队一次
      • 两者都要 visited 防重复；邻接表遍历 O(n+e)
      • 易错：邻接点次序不同序列不同；非连通图要从未访问顶点再启动
    • 40. 连通图与连通分量
      • 无向连通：任意两顶点有路径；连通分量：极大连通子图
      • 强连通（有向）：任意两点相互可达
      • n 顶点连通图至少 n−1 条边
      • 非连通图最少顶点：一个完全图 + 孤立点，用 n(n−1)/2=边数反推
    • 41. 最小生成树A
      • 生成树：含全部 n 顶点、连通无回路、恰 n−1 条边
      • 最小生成树：边权和最小；等权边时可能不唯一
      • Kruskal 挑边：按权递增选边，成环跳过，选满 n−1 条
      • Prim 扩点：任选起点，每次吸"已选集到外部"的最小边
      • 口诀：Kruskal 挑边，Prim 扩点
    • 42. 拓扑排序
      • 对象：有向无环图 DAG（AOV 网）
      • 步骤：①选入度 0 输出 ②删点删出边 ③重复
      • 多个入度 0 → 序列不唯一；有环 → 无法输出全部
      • 邻接表时间复杂度 O(n+e)
    • 43. 最短路径与图算法补充
      • Dijkstra 单源：源点 0 其余 ∞ → 每轮取未确定中距离最小者 → 松弛更新 → 重复

      • Floyd 任意两点：D[i][j] = min(D[i][j], D[i][k]+D[k][j])，k 逐个作中转
      • 关键路径（AOE，低频）：ve/vl、e=ve(i)、l=vl(j)−w；l−e=0 为关键活动

    • 44. 排序基本概念与稳定性S
      • 稳定：相等关键字排序前后相对次序不变
      • 稳定：直接插入、冒泡、归并、基数（口诀：插冒归基）
      • 不稳定：简单选择、希尔、快速、堆（口诀：选希快堆）
      • 效率衡量：关键字比较次数 + 记录移动次数
    • 45. 插入排序
      • 直接插入：前部有序区，每趟取无序区首元素从右向左比较、后移、插入
      • n 个元素 n−1 趟；最好 O(n)、平均/最坏 O(n²)；辅助 O(1)；稳定
      • 有序区 [4,12,23,48,96] 插 60：比 96 小、比 48 大 → 共 2 次
      • 希尔：按增量分组组内直接插入，增量递减最后必为 1；不稳定
    • 46. 交换排序
      • 冒泡：相邻比较逆序交换，每趟推一个极值到一端；固定 n−1 趟比较 n(n−1)/2
      • 最好 O(n)（无交换提前结束）；平均/最坏 O(n²)；稳定
      • 快速：选基准划分，小前大后，基准归位后左右递归
      • 平均 O(n log n)、最坏 O(n²)（基本有序时）；辅助栈平均 O(log n)；不稳定
      • 识别：某元素左边全小、右边全大 → 快排一趟结果
    • 47. 选择排序
      • 简单选择：每趟选无序区最小放前面；比较次数固定 n(n−1)/2；O(n²)/O(1)；不稳定
      • 堆排序：建堆 → 堆顶与末尾交换 → 缩小堆调整 → 重复
      • O(n log n)、辅助 O(1)；不稳定；每趟把极值放入最终位置
    • 48. 归并排序
      • 两个有序段合并为一个有序段；段长 1→2→4→8…
      • 趟数 = ⌈log₂n⌉；O(n log n)、辅助 O(n)；稳定；分治
      • 8 个逆序元素二路归并比较 12 次

      • 按个、十、百位分配到桶再收集；d 位关键字 d 趟

      • 一趟识别
        • 前部有序区扩大 → 直接插入；末端极值有序 → 冒泡

考点45插入排序（直接插入 + 希尔）S2024.10、2025.10、2026.04▼
45.1 直接插入排序
每趟把无序区第一个元素插入有序区的正确位置；n 个元素 n−1 趟；任意时刻前部（有序区）始终有序。
  • 稳定；比较/移动次数与初始排列有关
  • 手算插入比较次数：从后往前与有序区元素逐个比较。例：有序区 [4,12,23,48,96] 插入 60 → 与 96 比（小）、与 48 比（大）→ 共 2 次（2025.10-24）
  • 哨兵 r[0]：暂存待插元素，免去每次判断是否越界（2024.10-33 算法阅读）
45.2 希尔排序
按增量分组做组内直接插入；增量逐趟缩小，最后一趟增量必为 1。
  • 本质：直接插入的改进版（缩小增量排序）；不稳定
  • 增量范围：1 ≤ s ≤ n−1（下界 1，上界 n−1）
  • 2026.04 真题：增量从 n/3 起每趟 ÷3 → 两趟：第一趟 2,1,3,6,4,7,5,8；第二趟完全有序
  • 反推增量（2025.10-14）：把候选增量代入"按间隔分组"逐组验证是否有序
希尔排序不稳定——同值元素被分到不同组会跨越换位。最后一趟增量不是 1 则不能保证整体有序。 45.3 真题

考点46交换排序（起泡 + 快速）A2024.10、2025.10▼
46.1 起泡排序
相邻元素比较，逆序交换；每趟把当前最值"冒"到一端；n−1 趟；某趟无交换可提前结束。
  • 稳定；比较次数固定 n(n−1)/2（与数据无关）
  • 特征：每趟确定一个最值，末尾（或首部）若干元素有序
  • 例：6 个元素降序起泡 → 比较 6×5/2=15 次（2024.10-24）
46.2 快速排序
选基准（枢轴）做划分：小于基准放前、大于放后，基准落在最终位置；对两侧递归（分治思想）。
  • 两种划分：对调划分（左右指针找一对交换一对）、转移划分（挖坑填数）；两者结果可能不同但基准都归位
  • 平均 O(n log₂n)、最坏 O(n²)（初始基本有序时）；不稳定；空间 O(log₂n)（递归栈）
  • 判定特征：序列中存在某元素"左边的都比它小、右边的都比它大"⇒ 可能是快排一趟结果
【信号】"一趟后某元素左边全小右边全大"→快排划分；双指针原地划分大题就是快排的 partition。 图示：快排的一次划分——基准 49 一趟后落在最终位置，左边全小、右边全大。

考点47选择排序（简单选择 + 堆排序）A2024.10、2026.04▼
47.1 简单选择排序
每趟从无序区选出最小，与无序区首位交换；n−1 趟。
  • 比较次数固定 n(n−1)/2；不稳定
  • 特征：每趟确定一个最值放前部，前部有序且是全局最小的若干元素
  • 第一趟：最小元素与第 1 个元素交换（如 45,24,39,… → 24,45,39,…）
47.2 堆排序
  • 升序：建初始大根堆 → 堆顶与末位交换（最大值就位）→ 剩余元素重新调成大根堆 → 重复 n−1 趟
  • 每趟确定一个最大值放末尾 → 末尾若干元素有序且是全局最大
  • 不稳定；时间 O(n log₂n)；空间 O(1)（就地交换，辅助空间为常数）
堆排序虽用堆结构，辅助空间仍是 O(1)；辅助空间 O(n) 的是归并排序。 47.3 真题

  • 第八章 查找（考点 51—58）
    • 核心：ASL、折半查找、BST、AVL、B 树与哈希
    • 51. 查找基本概念与 ASL
      • 查找表 = 查找操作针对的记录集合；成功/不成功查找
      • ASL = Σ(pᵢ×cᵢ)；等概率 = Σ比较次数 ÷ n
      • 哈希表也用 ASL 衡量查找效率
    • 52. 顺序查找
      • 从头逐个比较，不要求表有序
      • 等概率成功 ASL = (n+1)/2；不成功比较 n 次（ASL = n）
      • 成功比较次数 = 目标所在位置序号（从 1 起）
    • 53. 折半查找S
      • 前提：顺序存储 + 元素有序
      • mid=⌊(low+high)/2⌋；目标小去前半 high=mid−1；大去后半 low=mid+1
      • 最多比较 ⌊log₂n⌋+1 次；判定树层数决定比较次数
      • 步骤：写 low/high/mid → 明确舍弃哪一半 → 记录比较序列 → 按层权重算 ASL
    • 54. 分块查找（索引顺序查找）
      • 前提：块间有序、块内可无序；索引存各块最大关键字
      • 步骤：查索引定位块 → 块内顺序查找
      • 易错：要求的是块间有序，不要求块内也有序
    • 55. 二叉查找树 BST
      • 左子树所有结点 < 根 < 右子树所有结点；左右子树也是 BST
      • 中序遍历 → 递增序列
      • 插入：从根比较，小往左、大往右，插到空位
      • 删除：叶直接删；单子树由子树顶替；双子树用直接前驱/后继顶替
      • 左子树有 k 个结点 ⇒ 根是第 k+1 小的值
      • 易错：要检查整个子树的大小约束，不能只看直接孩子
    • 56. AVL 平衡二叉树
      • 平衡因子 = 左高 − 右高 ∈ {−1,0,1}
      • 插入后沿路径找最近失衡结点调整
      • LL 右旋；RR 左旋；LR 先左旋左子树再右旋；RL 先右旋右子树再左旋

考点55二叉查找树（BST）A2025.10▼
55.1 定义（左小右大）
任一结点：左子树所有结点 < 根 < 右子树所有结点；左右子树也各是 BST（递归定义）。
别名：二叉排序树、二叉搜索树、二叉查找树（同一概念）。
只检查"每个结点与直接孩子"的大小关系不够——左子树里不能藏比根大的数，必须整棵子树都满足。 图示：BST 的"左小右大"——任一结点都成立，所以中序遍历天然得到升序序列。
55.2 关键性质与操作
  • 中序遍历 BST → 升序序列（左根右 × 左小右大 = 天然递增）——判 BST、求有序序列的钥匙
  • 生成：逐个插入，新元素从根开始比较下探到空位；插入顺序不同 → 树形不同（同一集合可长成单支斜树）
  • 查找：与根比较，小往左、大往右，路径由大小关系唯一决定
  • 删除三种情况：叶结点直接删；只有一棵子树用子树顶替；左右子树都有用直接前驱（左子树最右结点）或直接后继（右子树最左结点）顶替
  • 填值推理：按左右子树结点个数定根（左子树 k 个 ⇒ 根是第 k+1 小的值），逐层推理

单链表插入必须先接后断：s->next=p->next 再 p->next=s，顺序颠倒会断链丢后继。 链式存储"不要求连续"≠"一定不连续"；= 是赋值、== 才是判等；判空 head->next==NULL（带头结点）/ head==NULL（不带头）。 循环队列容量陷阱：数组下标 0~m 时容量是 m+1；判空判满都用双等号；rear 指向约定变了公式跟着变。 广义表表尾永远是"表"要套括号：Tail((c,d))=(d) 不是原子 d；表头表尾对子表要重新识别。 n0 = n2 + 1 与 n1 无关——题目给 n1 多半是干扰条件；"二叉树的度为 2"错，是"不超过 2"。 顺序栈先移指针还是先存元素，取决于 top 指向空位还是栈顶元素；两道真题（2025.10-6、2026.04-6）都考这个。 哈夫曼编码判"不可能"：某编码是另一编码的前缀（如 1 是 10 的前缀）即不可能；哈夫曼树不唯一。 存储结构三连辨析：最短路径用 Dijkstra；最小生成树用 Prim/Kruskal；WPL 最小是哈夫曼树。 折半查找两个前提缺一不可：顺序存储 + 有序；偶数个元素取前半段最后一个作 mid。 希尔排序、简单选择、快速、堆排序不稳定；稳定的是直接插入、起泡、归并、基数（插冒归基）。

考前速记▼
  • 四种逻辑结构：集合、线性、树、图；四种存储：顺序、链式、索引、散列
  • 算法五特性：输入(≥0)、输出(≥1)、有穷、确定、可行
  • 出栈序列数 = 卡特兰数 C(2n,n)/(n+1)；p₁=n ⇒ 第 i 个出栈 = n−i+1
  • 单链表插入：先接后断；判空：带头 head->next==NULL，不带头 head==NULL
  • 循环队列：个数 (rear−front+m)%m，判满 (rear+1)%m==front
  • 二维数组：行主序 (i×n+j)×d，列主序 (j×m+i)×d；子串数 n(n+1)/2+1
  • 广义表：表尾是表要套括号；长度看最外层，深度看括号层数
  • 二叉树：n0=n2+1；中序+先序（或后序）唯一确定；树的先序=对应二叉树先序，树的后序=对应二叉树中序
  • 哈夫曼：WPL 最小、不唯一、2n−1 个结点、前缀码
  • 图：无向 Σ度=2e，有向 Σ入度=Σ出度=e；DFS 用栈、BFS 用队（每点入队 1 次）；生成树 n−1 条边
  • 排序稳定口诀：插冒归基稳，选希快堆不稳；O(nlogn) 且稳定只有归并；一趟未必归位的是直接插入
  • 折半查找：顺序存储+有序；最多比较 ⌊log₂n⌋+1；BST 中序遍历升序；分块查找块间有序
  • 哈希：除留余数选质数；冲突=不同关键字同地址；线性探测+1 顺次、二次探测±i²、链地址拉链
