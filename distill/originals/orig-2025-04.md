### 第34题（算法设计题）
**【2025.04·算法设计34】** 无向图G采用邻接矩阵存储，存储定义如下：
```f
#define MAXV 50  //最大顶点个数
typedef struct {
int arcs[MAXV][MAXV];  //邻接矩阵，顶点关系（0或1）
int vexnum, arcnum;  //顶点数，弧数
VertexType vexs[MAXV];  //存放顶点信息
} MGraph;
```
设计算法求图G中顶点度的最大值。
(1)给出算法的基本设计思想。（4分）
(2)根据设计思想，采用C或C++语言描述算法，关键之处给出注释。（6分）
**答案：**
(1) 算法的基本设计思想：对于无向图的邻接矩阵，顶点的度是其对应行（或列）中1的个数。所以算法的基本思想是：遍历邻接矩阵的每一行，计算每行中1的个数（即对应顶点的度），同时记录最大的度值。
(2)
```f
// 求图G中顶点度的最大值的函数
int maxVertexDegree(MGraph G) {
int maxDegree = 0;  //用于记录最大的顶点度
for (int i = 0; i < G.vexnum; i++) {
int degree = 0;  //用于记录当前顶点的度
//遍历当前顶点所在行的所有元素
for (int j = 0; j < G.vexnum; j++) {
//如果邻接矩阵中当前元素为1，说明有边，顶点度加1
if (G.arcs[i][j] == 1) {
degree++;
}
}
//更新最大顶点度
if (degree > maxDegree) {
maxDegree = degree;
}
}
//返回最大顶点度
return maxDegree;
}
```
