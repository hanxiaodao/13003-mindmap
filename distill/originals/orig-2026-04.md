### 第1题（单选题）
**【2026.04·单选1】** 在数据结构中，从逻辑上可以把数据结构分成（　）。
- A. 动态结构和静态结构
- B. 紧凑结构和非紧凑结构
- C. 线性结构和非线性结构

**答案：C**

### 第16题（问答题）
**【2026.04·问答16】** 简述递推法的思想。
**答案：** 根据递推关系，能从已求得的问题规模为1,2,…,i-1的一系列解，构造出问题规模为i的解。求解规模为i的解时，有时可能仅需规模为1,2,…,i-1的系列解中的一部分，而不是全部。

### 第17题（问答题）
**【2026.04·问答17】** 简述二叉树与度为2的树之间的差别。
**答案：** 二叉树的子树有严格的左右之分，其次序不能任意颠倒，某个结点即使只有一棵子树，也区分是左子树还是右子树，而在度为2的树中，某个结点只有一棵子树时，是不区分左右的。除此之外，二叉树可以是空树，而度为2的树至少有一个度为2的结点，所以不能为空树。

### 第19题（问答题）
**【2026.04·问答19】** 简述顺序查找方法的基本思想。
**答案：** 顺序查找方法的基本思想是从顺序表头开始，用给定的目标与表中各记录的关键字值逐个进行比较。如果表中存在目标，则进行若干次比较后，一定能够找到目标。如果表中不存在目标，则比较到表尾也不会出现相等的情况。

**【2026.04·问答22】** 阅读下列算法（顺序栈的元素类型为ElemType），并回答问题：

void fun(SqStack *&st, ElemType x)
{   SqStack *tmps; ElemType e;
    InitStack(tmps);
    while (!StackEmpty(st))
    {   Pop(st, e);
        if (e!=x) Push(tmps, e);

    {   Pop(tmps, e);
        Push(st, e);

}

int DFSTrave(AdjGraph *G)
{   int k, num=0;    (1分)
    for (k=0;k<G->n;k++)    (1分)
        visited[k]=0;    (1分)
    for (k=0;k<G->n;k++)
        if (visited[k]==0)    (1分)
        {   num++;    (1分)

        }
    return num;    (1分)
