### 第1题（单选题）
**【2024.10·单选1】** 下列任何两个结点之间都没有逻辑关系的是（　）

- B. 线性结构

### 第5题（单选题）
**【2024.10·单选5】** 读入数据元素序列a, b, c, d, e, f, g并入栈。下列选项中，不可能是出栈序列的是（　）
- A. f, e, g, d, a, c, b
- B. c, d, b, e, f, a, g
- C. e, f, d, g, c, b, a
- D. d, e, c, f, b, g, a
**答案：A**
解析：f出栈后，栈内自底向顶为a、b、c、d、e；e、d出栈后，此时栈顶是c，不可能出栈a，所以不可能的出栈序列是A。

### 第6题（单选题）
**【2024.10·单选6】** 若以1，2，3，4作为双端队列的输入序列，则既不能由输入受限的双端队列得到，又不能由输出受限的双端队列得到的输出序列是（　）
- A. 1, 2, 3, 4
- B. 4, 1, 3, 2
- C. 4, 2, 3, 1
- D. 4, 2, 1, 3
**答案：C**
解析：核心：3一定不会在1和2的中间——设1和2已入队且2与1相连，第3个入队的是3，无论它从哪一端入队，都不会插入到1和2的中间；A、B、D均可由受限双端队列得到。

### 第33题（算法阅读题）
**【2024.10·算法阅读33】** 阅读下列算法，并回答问题：
```f
void func(int r[], int n)
{ int i, j;
for(i=2;i<n;i++)
{ r[0]=r[i];
j=i-1;
while (r[0]<r[j])
{ r[j+1]=r[j] ;
j=j-1;
}
r[j+1]=r[0];
}
}
```
（1）这是哪一种插入排序算法？该算法是否稳定？
（2）设置r[0]的作用是什么？
**答案：**
（1）直接插入排序；该算法稳定。
（2）r[0]用来存储每次待插入的元素，免去查找过程中每次都要检测整个表是否查找完毕，提高了查找效率。

### 第34题（算法设计题）
